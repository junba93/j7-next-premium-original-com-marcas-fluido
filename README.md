# J7 Energia Solar - Site Premium

Projeto em Next.js com Tailwind, Framer Motion e fotos reais da J7 Energia Solar.

## Rodar localmente
npm install
npm run dev

## Publicar na Vercel
1. Suba estes arquivos para um repositório no GitHub.
2. Acesse vercel.com.
3. Importe o repositório.
4. Clique em Deploy.
